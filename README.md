# JavaScript Basics | My First Programming Project

## Project Overview
This repository documents my introduction to HTML and JavaScript programming. The project displays a Hello World heading on a webpage and prints a message to the browser's developer console.

As a Cybersecurity Management graduate student at the University of Maryland Global Campus, I am building foundational technical skills to better understand web applications and cybersecurity.

## Technologies Used
- HTML5
- JavaScript
- Browser Developer Tools
- GitHub

## Project Files
- `index.html` — Creates the webpage and connects the JavaScript file.
- `index.js` — Prints a Hello World message to the browser console.
- `README.md` — Explains the project and how to run it.

## JavaScript Code Example
```javascript
// My First JavaScript Code!
console.log("hello world");
```

## How to Run the Project
1. Download or clone this repository.
2. Keep `index.html` and `index.js` in the same folder.
3. Open `index.html` in a web browser.
4. Press F12 and open the Console tab.
5. Confirm that `hello world` appears.
